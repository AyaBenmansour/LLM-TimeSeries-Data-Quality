# Specification decisions and limits

The implementation follows the brief's explicit corrections, then the Burst amendments and compact framework, then the November protocol. The project-description PDF supplies the research objective. All numerical presets are editable experiment settings. | Decision | Implemented interpretation |
| --- | --- |
| Boundaries for localization (researcher correction) | A point earns a defect label only when its value, recorded time, or presence actually changes. A ramp's unchanged starting point, an unchanged recovery endpoint, and unchanged observations between clipped peaks remain clean. Episode bounds run from the first affected observation to the last. Use exact record IDs for point-level scoring and the scheduled support for generator provenance. |
| Flat Line | Outlier Flatline uses a held value outside the configured statistical interval. Hardware limits remain independent metadata. Legacy input `hard_over` resolves to the corrected label. Magnitude and duration have separately recorded severity axes. |
| Burst | Five normalized deterministic error profiles. The first corrupted transition must strictly exceed the selected healthy rate threshold on its actual gap. Contextual candidates require positive local IQR, a local exceedance and globally in-range values throughout. The configurable shortness guard and meaningful-change tolerance control ambiguity. Two-point constant discretizations are rejected. |
| End behavior | Recovery means the generator stops adding error. A record ending at the Burst boundary has no observed recovery sample. An optional residual takes the last signed Burst error times an explicit residual fraction and creates a subsequent Bias label. Drift recovery uses actual elapsed time. |
| Normal ranges | Default Tukey fences, selectable empirical quantiles or mean plus/minus a configured scale multiple. Report the mode, reference and achieved boundary exceedance. Residual variability for Noise is estimated separately. |
| Duration presets | The default reference window is 100 samples. The Noise duration starts at 0.2 reference windows to meet the separate 20-point pilot minimum. Researcher-selected absolute lengths for families lacking a unique PDF duration are recorded in the preset. |
| Missing Values | Mask geometry describes isolated, block, terminal, whole-channel and overlapping multi-channel episodes. Terminal means the observed missing span reaches the end. A whole-channel span takes precedence. Intentional missing episodes on a channel retain at least one intervening sample. |
| Fixed clock shift | Both signed absolute physical-time errors and median-gap-relative presets are available. The irregular P95 lower bound is removed. A whole-channel offset requires independent timing evidence. Strict boundary-order policies can make a large interior shift infeasible. |
| Timing stresses | Time stretch, exact/near copies and declared erroneous civil-time offsets require explicit enabling. DST simulations use the configured time and signed offset. A civil-time shift requires declared timezone metadata. |
| Unobservable targets | Absent event-driven records require an expected-reporting rule or reference. Clean/visible context and the data-needed code travel with the label. Conditions describe evidence supplied to an evaluator. Matching the synthetic rule alone does not demonstrate causal identifiability. |
| Scheduling and scoring | Fixed-count attempts, independent Bernoulli opportunities and the final accepted count are distinct. Probabilities for episode starts and missing fractions have separate fields. Window mixing selects from what the generated stream actually contains and reports impossible class quotas. A reviewed list of natural-change record IDs can identify genuine changes in clean controls. |

The initial benchmark defers MCAR/MAR/MNAR mechanism generators, experimental rectangle/random Burst shapes, arbitrary unparsable timestamp strings, and automatic detection or repair. The optional elapsed-time occurrence-rate model is also deferred. The scheduler supports explicit Bernoulli opportunities and fixed counts in regions or on physical-time grids. The researcher sets channel selection, split eligibility, domain context and tolerance. The engine does not infer natural regime boundaries or sensor limits. Restrict allowed regions to curated healthy intervals or supply eligible calibration IDs.

Equal normalized severity across families can yield different magnitudes, extents and task impacts. Empirical realism, threshold calibration, downstream task-impact scores and LLM performance require experiments on the selected research datasets. The automated tests exercise transformations, visibility and reproducibility.
